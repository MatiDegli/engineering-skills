# Team criteria

Apply these criteria when several people maintain the project; see the
[areas table](criteria.md#areas) and the [project's shape](criteria.md#project-shape). Otherwise
close the area in Coverage with `TEAM-* (one maintainer)`.

| ID | Check | Applies when | Guide |
| --- | --- | --- | --- |
| TEAM-01 | Each area has an owner, and someone other than the author approves each change, always for security, release, and policy changes | Several maintainers | [standard](standard.md#repository) |
| TEAM-02 | Commit messages follow a consistent convention, enforced if the project adopted one | History available | [commits](commits.md#naming) |
| TEAM-03 | Work that outlives a change names one owner: temporary files and code paths, suppressions, recorded debt, dependencies, and adopted tools | Such work exists | [standard](standard.md#repository) |
