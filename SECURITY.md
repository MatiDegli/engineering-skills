# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open public issues for security problems.

Relevant reports include skill instructions that could make an agent take unsafe actions, leave its
read-only scope, follow instructions planted in an audited repository, or expose secrets, as well as
flaws in the maintenance tools and workflows.

## Supported versions

Fixes are made on `main` and in the latest release. This project is maintained by one person, so
responses are best effort.
